# Source recordings

The Book5 task recording is published as a silent, frame-identical copy in
[examples/source-recording](../examples/source-recording/README.md). Its provenance
file records original and published hashes. Other takes and the original file
with audio remain local and Git-ignored.

Derived artifacts retain the input hash. Camera scale, depth and hidden contacts
are inferred or assumed; the video does not provide measured 3D ground truth.
